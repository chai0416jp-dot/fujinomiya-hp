# データ管理ガイド（問い合わせ／Partners通信）

サイトのフォームから集まる個人情報を、**用途ごとに1か所へ集約**して管理するための手順です。

---

## 全体像：どこに何がたまるか

| 経路 | 一次通知 | 台帳（保存先） | 一括配信 |
|---|---|---|---|
| お問い合わせ（`index.html`） | メール → `info@fpartners.jp`（FormSubmit） | **Google スプレッドシート「contacts」シート** | 告知時に台帳から抽出して Brevo にインポート／差し込み送信 |
| Partners通信 配信登録（`partners-news.html`） | メール → `info@fpartners.jp`（FormSubmit） | **Google スプレッドシート「newsletter」シート** ＋ **Brevo の購読リスト** | **Brevo のキャンペーン機能**でリスト宛に一括送信 |

- 記録用スクリプト：`apps-script/form-handler.gs`（Google Apps Script）
- スクリプトの URL を差し込む場所：`index.html` と `partners-news.html` の `var LOG_ENDPOINT = '';`
- どちらのフォームも、`LOG_ENDPOINT` が未設定でも**メール通知だけは動きます**（今の状態）。

---

## セットアップ手順

### STEP 1. 台帳（Google スプレッドシート）を用意する

1. Google ドライブで新規スプレッドシートを作成（例：「フジノミヤパートナーズ フォーム台帳」）
2. メニュー **拡張機能 → Apps Script** を開く
3. `apps-script/form-handler.gs` の中身を全文コピーして貼り付け、保存
4. 先頭の `SETTINGS` を必要に応じて編集（当面は `NOTIFY_EMAIL` だけ確認すれば OK）
5. **デプロイ → 新しいデプロイ → 種類「ウェブアプリ」**
   - 説明：任意（例：v1）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
6. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）をコピー
7. `index.html` と `partners-news.html` を開き、`var LOG_ENDPOINT = '';` の `''` の中に URL を貼り付けて保存
8. サイトを再アップロード
9. 各フォームからテスト送信 → スプレッドシートに `contacts` / `newsletter` シートが自動作成され、1行増えることを確認

> スクリプトを直すたびに再デプロイが必要です（「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」）。

### STEP 2. Brevo（メール配信）を連携する ※Partners通信のみ

1. <https://www.brevo.com/ja/> で無料アカウントを作成
2. **Contacts → Lists** で購読者用リストを作成（例：「Partners通信」）。作成後、URL や一覧に出る **リスト ID（数字）** を控える
3. **右上メニュー → SMTP & API → API Keys** で **v3 API キー** を発行（`xkeysib-...`）
4. Apps Script の `SETTINGS` を編集：
   ```
   BREVO_API_KEY: 'xkeysib-ここに貼り付け',
   BREVO_LIST_ID: 3   // ← 手順2のリスト ID
   ```
5. Apps Script を**再デプロイ**（新バージョン）
6. 配信登録フォームからテスト → `newsletter` シートの「Brevo登録」列が `OK` になり、Brevo のリストにも入ることを確認

> API キーはスクリプト内（サーバー側）だけに置きます。HTML には出ません。

### STEP 3.（任意）ダブルオプトインにする

より丁寧にするなら、Brevo の **Double Opt-In** 用フォーム／自動化を設定し、登録者に確認メールを送る運用にできます。
その場合は Brevo が発行する購読フォーム URL を `partners-news.html` の `<form action>` に使う方式へ切り替えます（必要になったら対応します）。

## 運用：告知・配信のしかた

### Partners通信を送る

1. Brevo → **Campaigns → メールキャンペーンを作成**
2. 宛先：手順で作った購読リスト
3. 本文を作成して送信／予約。配信停止リンクは Brevo が自動で挿入します（法令上必須）。

### 問い合わせ客に新サービスを案内する

1. `contacts` シートを開き、**「ご案内メール希望」列が「希望する」** の行だけを抽出
2. その `メールアドレス` を CSV でエクスポート
3. Brevo に**別リスト**（例：「お客様（案内可）」）としてインポート
4. そのリスト宛にキャンペーンを送信

> チェックの無い（「（未チェック）」の）アドレスには広告・宣伝メールを送らないでください（特定電子メール法）。
> 同意の記録は `contacts` シートの受信日時＋「ご案内メール希望」列が証跡になります。

---

## 法令メモ（要点）

- **広告・宣伝メール**（新サービス案内・キャンペーン等）は、**事前の同意（オプトイン）** と **配信停止手段** が必須。
  - Partners通信：登録フォームの同意チェック＝オプトイン。配信停止は Brevo が処理。
  - 問い合わせ客への案内：フォームの任意チェック「ご案内メールを受け取る」にチェックした人のみ。
- **利用目的**はプライバシーポリシー（`privacy.html`）に明記済み（第4項）。委託先（FormSubmit / Google / Brevo）も第6項に記載。
- 開示・訂正・削除等の請求窓口：`info@fpartners.jp`（同ポリシー第9項）。
